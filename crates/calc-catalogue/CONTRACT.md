# calc-catalogue contract

CalcCatalogue holds the shared Excel function declarations and file spellings. CalcFunc attaches execution
kernels. CalcFml consumes the declarations for formula admission and CalcDoc uses the file spellings.

- Look up a declaration by stable `FunctionId` with `declaration` or enumerate `declarations`
  (`src/registry.rs:189`, `src/registry.rs:250`). A declaration carries the function's spelling,
  parameter and entry metadata, and kind (`src/declarations.rs`). `DeclarationRef::parameter`
  resolves a zero-based call position through declared `ArgumentGroups` before falling back to the
  final named parameter.
- Query `parameter_lifting` with the declaration, zero-based position, formula mode and argument
  origin. It derives the call policy for optional and repeated positions, combining CalcFml
  argument preparation with declared kernel-lifted parameters (`Parameter::kernel_lifts`). The
  handbook and binding table is generated by the `export_parameter_lifting` example.
- `file_prefix` maps a name to its known Excel package prefix. The file table also covers names beyond the
  executable catalogue (`src/lib.rs:1`, `src/lib.rs:166`). Parameter and function-value names have their
  own file prefixes (`src/lib.rs:17`).
- The admission export test exercises the declared families (`tests/admission_export.rs`). Runtime
  volatility evidence for names and SUMIF/AVERAGEIF is tracked in dc-1nbp.9 and dc-hsa5.20.2.
