# Excel-DNA/samples inventory and DNA Calc surface mapping

Full static inventory of [`Excel-DNA/samples`](https://github.com/Excel-DNA/samples) for epic `dc-z05nj` (task `dc-z05nj.1`). Machine-readable companion: `docs/plan/exceldna-samples.tsv` (115 rows). Collected defects in the samples repository itself: `docs/plan/exceldna-samples-problems.md`.

## Snapshot and measured counts

- **Samples repository commit:** `ba5732c7d67d65fbc8610f714371f178aa0e5a8d` (read-only clone, 2026-11-24).
- **DNA Calc baseline checked:** commit `64a2f2d35` (2026-11-24; `docs/architecture/C_API_COMMANDS.md`, `OBJECT_MODEL.md`, `API_FACES.md`, `crates/calc-xll-host`, `crates/calc-object-model`, `crates/calc-host`, `crates/calc-com-host`).
- **Top-level folders:** **41** — 38 modern SDK-style sample folders, `ArrayResizer` (2 `.dna` + C#/VB sources), `Misc` (2 standalone `.cs` snippets), and `Archive` (59 `.dna` files + 1 legacy `.csproj`). *(Note: the epic description estimated 42 folders and ~30 Archive `.dna` files before counting; the measured counts below supersede the estimate.)*
- **Projects:** **52** total (51 SDK-style + 1 legacy non-SDK `Archive/Async/AsyncFunctions/AsyncFunctions.csproj`).
  - Target frameworks: `net472;net6.0-windows` (**38**), `net472` (**7**), `net462;net6.0-windows` (**4**), `net8.0-windows` (**2**), legacy `v4.5` (**1**).
  - Package versions: **48 of 52** projects use floating `*-*` versions; 3 SDK-style projects pin explicit versions (`CustomTaskPane` `1.7.0-rc9`, `RibbonFSharp` `1.6.0`/`15.0.1`, `RtdClock-ExcelRtdServer-PreRegistered` `1.8.0`); 1 legacy project uses `packages.config` + dead `HintPath`.
  - Package ID casing: **41** use `ExcelDna.Addin` (lowercase `i`) vs **6** using canonical `ExcelDna.AddIn`.
- **`.dna` files:** **61** total (**59** under `Archive/`, **2** under `ArrayResizer/`). Note that `Archive/Async/AsyncFunctions/AsyncFunctions.dna` is the loader paired with `Archive/Async/AsyncFunctions/AsyncFunctions.csproj`.
- **Standalone code snippets:** **2** (`Misc/ComObjectModel.cs`, `Misc/RegistrationInfoDump.cs`).
- **Documentation / test workbooks (40 non-Archive folders):** **14** lack a `README.md`; **33** lack a test workbook (only 7 ship one: `ComServer`, `DnaComServer`, `GetInfoFunctions`, `ObjectHandles`, `Registration`, `RtdPerformance`, `Testing`).
- **Total inventory entries (`exceldna-samples.tsv`):** **115** (51 modern projects + 2 `ArrayResizer` `.dna` + 2 `Misc` snippets + 1 legacy `Archive` project + 59 `Archive` `.dna` files).
