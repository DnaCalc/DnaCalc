# Release notes draft: planned 0.2.0 preview

Draft of user-visible changes since the `2026-11-09` public web builds (`dnacalc.com` at `779e136e9c4f` and `onecalc.dnacalc.com` at `c27d1c615516` in `deploy/site/published.json`), prepared for the planned `0.2.0` preview (`docs/site/layout.json`). Nothing in this draft is published yet.

## Classic grid editing and worksheet views

- **Formula entry and Excel-style navigation:** Starting a formula with `=` arms Point mode (`F2` toggles between Point and text edit), letting you pick cells and ranges with arrow keys or mouse drag (including across sheets). Pressing `F4` cycles A1 and range endpoints (`A1` → `$A$1` → `A$1` → `$A1`), `Ctrl+F2` moves an active edit between the cell and the Formula Bar, `Enter`/`Tab` (with `Shift`) walk selections, `Ctrl+Enter` fills the selection in one undo step, `Alt+PageUp`/`Alt+PageDown` page horizontally, and **Go To Special** selects formulas, constants, or blanks. (`dc-971p.67`, `dc-971p.68`, [classic-grid.md](../../user/classic-grid.md))
- **Clipboard, drag, fill, and tabs:** System clipboard copy/cut/paste exchanges TSV and inert HTML tables alongside internal workbook snapshots (`Paste Special` for `Values`, `Formulas`, `Cell formats`, and `Transpose`, plus an overwrite confirmation dialog). Border drag moves or `Ctrl`-copies ranges with reference updates, the fill handle and **Flash Fill** (`Ctrl+E`) fill series and patterns, sheet tabs support context actions and drag reordering, and the status bar toggles configurable selection aggregates. (`dc-971p.68`, `dc-971p.74`)
- **Zoom, panes, spills, notes, and formatting:** `Ctrl+wheel` zooms the worksheet (scaling cell geometry and text and persisting on save), freeze and split panes load and toggle from the UI, row/column drag-resize and AutoFit fit wrapped and stacked text, row/column headings size from visible digits, and imported font effects (outline, shadow, accounting underline) and number-as-text warnings (`ignoredErrors`-aware) render in the grid. Hovering comments/notes shows previews, hyperlinks open, conditional formatting rules can be managed, and filled or blocked `#SPILL!` ranges show outlines with read-only child explanations. (`dc-971p.63`, `dc-971p.69`, `dc-971p.70`, `dc-971p.43.3`, `dc-971p.43.4`)
- **AutoFilter, sorting, drawings, sparklines, and print preview:** Authored AutoFilter criteria (including date-period and above/below-average filters) and row sorting (including under criteria-free AutoFilters) apply on the worksheet. Shapes, connectors, and sparklines read, draw on both the grid and print pages, and round-trip on save. Print preview persists page views and manual page breaks and shows closed-workbook link cache values and iteration-off circular values with their provenance. (`dc-971p.37`, `dc-971p.38`, `dc-971p.65`, `dc-zjsg.2`–`.9`, `dc-ylr`, `dc-y2o.1`)
- **One controller across six skins:** Grid, Notebook, Atlas, Tree, Canvas, and Ledger share one controller and worker projection so switching skins keeps your selection, undo/redo history, and active formula draft intact. (`dc-xfrhg`)

## File formats and the Linux runner

- **`.xlsx` preservation:** Round-trip preservation now covers review metadata, drawing/control storage, CustomXML, rich/phonetic shared strings, stored range selections, sparkline extensions, updated `oneCell` and absolute chart anchors when rows or columns resize, and repaired literal fallbacks for rejected formula scalar caches. (`dc-nn9`, `dc-971p.43.2`, `dc-zjsg.14`, `dc-mx3x.1`)
- **`.xlsb` reading:** Binary workbooks now read chart sheets and resolve mixed-case binary part targets. (`dc-cazfj.1`)
- **`.xls` (BIFF2–BIFF8) reading:** Legacy BIFF workbooks now decode raw BIFF2/3/4 cells, geometry, and colours (`dc-4j0e.14`), continued BIFF5 byte strings (`dc-4j0e.8`), two-argument BIFF8 `GETPIVOTDATA` (`dc-4j0e.3`), XLS data-table formula membership (`dc-4j0e.3`), clean hyperlink URL monikers (`dc-4j0e.4`), trailing-word phonetic runs (`dc-4j0e.2`), decrypted legacy pivot-cache streams and saved XLS pivot caches with refresh disabled (`dc-4j0e.13`), and large DIFAT embedded projects (`dc-4j0e.1`).
- **Command-line runner (`dnacalc`):** The `dnacalc` CLI (`recalc`, `diff`, `get`, `set`, `run`) ships as static Linux x86-64 tarball (`11 MB`) and `.deb` (`7.8 MB`) packages verified on clean `ubuntu:26.04`, plus cross-built `dnacalc.exe` for Windows. (`dc-icq4.1`, `dc-icq4.2`)

## VBA

- **Macro security and discovery:** Workbooks with macros open with VBA disabled (`Off`, `Guarded`, `Unguarded`; renamed from `Safe` in `dc-8ovd`). The blocked-macro bar reports the real file-origin block reason (`Zone.Identifier`, network origin, or browser bytes), and enabling macros refreshes workbook VBA completion inside any open formula draft. (`dc-15dk`, `dc-0f1k.22`, `dc-a3fza`, `dc-971p.71`, `dc-2nn1`)
- **Real Automation `VARIANT` and single-COM-object runtime (`dc-yqq0`, 29/29 tasks):** CalcVBA now uses the platform's real Automation `VARIANT` (`24` bytes on 64-bit, `16` bytes on 32-bit/`wasm32`) and one COM object per VBA class instance with no wrapper layer. This brings Excel-matching `SAFEARRAY`s and `SAFEARRAY(VT_RECORD)`, `VarPtr`/`StrPtr`/`ObjPtr` and `VT_BYREF` aliasing, direct `Declare` and JIT `AddressOf`, lossless UTF-16 strings, `Implements`, `WithEvents` connection points, Excel-matched `ITypeInfo`/DISPID ordering, `ISupportErrorInfo`, and Win64 early-bound vtable slot thunks across VM3 and the JIT. ([calcvba-variant.md](../../articles/calcvba-variant.md))
- **Workbook UDF parity:** Compiled workbook VBA procedures publish metadata and parameter descriptions (`dc-snz.15`), and `ParamArray` UDFs run inside document events (`dc-hsa5.23`). Measured sets match Excel across `dna-simple` (`109 of 109` on module, JIT, and `.xlsm` routes in `crates/calc-vba/tests/corpus/baseline.json`), `VBA-Dictionary` (`15 of 15`), `VBA-JSON` (`21 of 21`), `StringBuilder` (`35 of 35`), and `VBA-Web` (`45 of 45`) on VM3 and JIT (`dc-tey4.3`, `dc-tey4.4`, `dc-g4mj3`).

## Add-ins (Windows x64)

- **Isolated XLL and XLAM hosting:** Both Windows desktop apps load `.xll` and `.xlam` add-ins in a surrogate process with **Stop** and **Restart** controls, register functions through `xlfRegister` into autocomplete and signature help, support async UDFs via `xlAsyncReturn`, match Excel's `MESSAGE` lifecycle return values (`dc-6332.10`), and use a pure-Rust COM projection (`dc-0f1k.23`, `dc-0f1k.10`, `dc-1nbp.4`, `dc-1nbp.5`).
- **Workbook identity and events in DNA Calc desktop:** With `--engine`, `dna-calc-desktop` exposes the session workbook and `SheetChange`, `SheetCalculate`, and `AfterCalculate` events through `Application.EnableEvents` (`dc-1nbp.3`: `xlOil events 16/16`, `Excel-DNA events 6/6` values and `39/39` ordered event records, `X4 12/12` against Excel 16.0).
- **Real-time data (`=RTD()`):** `RtdConnector` and initial topic values flow through `read_topic` (`dc-snz.23.3`, `dc-snz.23.4`).
- **Windows cross-build acceptance (`docs/plan/WINDOWS_CROSS_BUILD.md`, second run):** Formula Explorer XLL `m4` cases matched **`350 of 350`** (`xloil-utils-sql` `12 of 12`), VBA add-in `m5` sets matched **`109 of 109`** each on `simple-xlam` and `simple-xlsm`, **`22 of 22`** on `dnaexamples-xlam`, and **`23 of 23`** on `dnaexamples-xlsm`, and DNA Calc desktop page cases matched **`729 of 732`** (`887ebb5e`).

## Formula Explorer

- **Public naming and embedding:** Publicly named **DNA Calc - Formula Explorer** (`OneCalc` remains the internal name). Embedded instances on web pages no longer overwrite the host page title. (`dc-sdzi1`, `dc-6q2k.5`)
- **Native add-in bench and sessions:** The Windows desktop host adds a native `.xll` file picker and surrogate session host (`dc-0f1k.10`, `dc-r0vsc`), opens legacy `.xls` and `.xlsb` workbooks (`dc-4j0e.10`), saves sessions in a constrained `.xlsx` format (`dc-0f1k.5`), and enforces a strict values-only ceiling (explicitly refusing `As Range`, `Caller`, and `ThisCell` rather than faking an object model, `dc-svqh`, `dc-snz.5`).
- **Workbench UI:** Caret-positioned completion and signature popups, collapsed `Inputs` scratch grid, scrollable array viewer, Effective Display / Formatting / Conditional Formatting panels, `F9` sub-expression evaluation, step-by-step evaluation trace, and full 64-bit hex inspection. (`dc-0f1k.15`–`.20`)

## Known gaps in this draft

- **Installers and signing:** Signed Windows installers and clean-machine install, upgrade, and uninstall verification remain open (`dc-fk66.2`, `dc-fk66.3`). Publishing `0.2.0` awaits owner review (`dc-6q2k`, `dc-6q2k.1`).
- **Platform requirements:** Windows desktop apps require the Microsoft Edge WebView2 Runtime. Native XLL add-ins are Windows x64 only and are refused on Linux and in the browser.
- **Add-ins and VBA still open:** WebView2 page-route add-in event timing (`dc-1nbp.3.1`), saved-workbook `FullName`/`Path` comparisons (`dc-1nbp.3`), remaining CalcVBA COM object identity follow-ups (`dc-69djs`), library named arguments (`dc-q6brh.1`), and compile/runtime fixes for third-party projects such as `vba-test`, `vba-regex`, and `vba-arraytools` (`dc-tey4.8`–`.10`, `dc-tey4.5`) remain open. Formula Explorer remains an intentional values-only host (`dc-svqh`).
- **Formula and workbook coverage still open:** `31,630` full-bank rows across `80` non-exact functions remain open (notably `BETA.DIST`, `GAMMA.DIST`, `GAMMA.INV`, `BETA.INV` `dc-iuwct.51`, `T.DIST`/`T.DIST.2T`/`TDIST` `dc-iuwct.65`/`dc-iuwct.66`, `BINOMDIST` `dc-iuwct.52`, and `NEGBINOM.DIST` `dc-iuwct.63`), along with `129` oracle workbook cells (`73` external-link holds under `dc-ylr`, `14` circular holds under `dc-y2o.1`, `37` numeric mismatches, and `5` HJD D4:D8 cells under `dc-mx3x`) and Enron text-to-number/date coercion (`dc-3k5n`).
- **Grid, print, and file gaps:** Remaining Classic grid parity items (`dc-971p.74`), Windows/Excel pixel measurements (`dc-971p.62`), Page Setup controls (`dc-971p.57`), print-preview shape CSP fixes (`dc-zjsg.12`), workbooks with chart or dialog sheets (`dc-hc85`), and remaining `.xls`/`.xlsb` record coverage (`dc-4j0e.*`, `dc-cazfj.1`) remain open.
