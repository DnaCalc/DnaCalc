The Rust/Wasm browser mount is experimental. Pin the source and build together. At 539c4234, dna_onecalc::surface::mount takes an HtmlElement, appends the workbench and returns a Mounted handle. Retain it while the workbench is visible and drop it to unmount. The site uses this path for the workbench above.

Use the workbench controls to enter the formula and inputs. Enter =ROUND(A1,2), set A1 to 1.234 and read 1.23 in Result. Syntax diagnostics and unavailable-input messages appear in the UI. The mounted browser tests exercise this interaction path.

The proposed JavaScript component would accept a host element, an optional initial formula and typed cell inputs. It would report each evaluation as a typed value, a formula diagnostic with a source span, or a refusal with a reason. Disposal would unmount and stop notifications. These initialisation and notification hooks are a design proposal. Desktop bridge messages, worker messages and generated asset URLs are internal.
