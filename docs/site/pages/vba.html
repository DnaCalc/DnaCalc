VBA outside Excel

CalcVBA runs the tested VBA worksheet functions outside Excel. The execution route and the workbook project both affect coverage.

Choose a host

To embed the standalone CalcVBA runtime, see its pinned hosting reference for project lifetime, capabilities and backend choice. In DNA Calc, the Rust calc-vba adapter is internal. Its workbook profile can supply workbook objects. The values-only Formula Explorer profile can run value-based calls and refuses host services that require workbook object context.

The file routes are experimental. With macros enabled on a trusted .xlsm, the workbook host uses that file's embedded project. On Windows x64, load a trusted .xlam through the desktop Add-ins panel to register its exported UDFs. VBA availability and services vary by host and policy.

For a values-only example, follow the mounted Formula Explorer VBA test at 539c4234. It loads a simple module, sets A1 to 40 and evaluates =Module1.Add2(A1,2) to 42. A UDF declared with an As Range parameter instead produces a typed refusal in this profile, with the diagnostic needs a workbook: open in DNA Calc.
