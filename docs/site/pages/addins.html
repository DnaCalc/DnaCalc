Test an add-in

The Windows Formula Explorer preview exercises native XLL and VBA add-in functions against recorded Excel answers.

In the Windows preview, open the Add-ins panel and load an add-in from a source you trust. Enter a formula for one exported function and compare its value and type with Excel. Calls to unmodelled services can return a typed refusal.

XLL callbacks in the preview

The host uses xlfRegister to collect function names, signatures and help. The desktop can also receive native asynchronous results through xlAsyncReturn. The tested coverage varies by registration and call path.
