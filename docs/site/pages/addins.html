Test an add-in

The Windows Formula Explorer preview exercises native XLL and VBA add-in functions against recorded Excel answers.

In the Windows preview, open the Add-ins panel and load an add-in from a source you trust. Enter a formula for one exported function and compare its value and type with Excel. Calls to unmodelled services can return a typed refusal.

Windows x64 preview example

The XLL and XLAM routes are experimental. Use the add-in bench walkthrough at 539c4234. Build its X2Hello fixture on Windows, load X2Hello-AddIn64.xll in Formula Explorer and enter =SayHello("Excel-DNA"). Compare the text result Hello, Excel-DNA with the same function and argument in Excel.

XLL callbacks in the preview

The host uses xlfRegister to collect function names, signatures and help. The desktop can also receive native asynchronous results through xlAsyncReturn. Formula Explorer invokes the registered function in its formula field. DNA Calc desktop invokes it from a workbook cell through its own Add-ins panel. XLAM exports come from a VBA project and use the workbook or values-only host described in the VBA guide. See the Formula Explorer callback and acceptance reference.
