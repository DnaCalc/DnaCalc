Check a workbook without Excel

The Linux x86-64 runner recalculates Excel workbooks, reads and edits cells, and reports the result from a script.

dnacalc diff book.xlsx compares every formula cell with the workbook's saved value. --json writes a machine-readable result.

{{runner}}

For diff, exit status 0 means every formula cell matched. Status 1 means at least one formula cell mismatched, was refused, had no saved value, or failed. Status 2 means a usage error or a typed refusal.

Runner preview contract

The Linux x86-64 runner and its JSON output are experimental. Use the 0.1.0 runner built at commit 539c4234 for these examples. Download the site sample as book.xlsx.

dnacalc recalc book.xlsx --out checked.xlsx --json
dnacalc diff checked.xlsx --json

The second command compares fresh results with the caches saved in checked.xlsx. To compare with the original workbook's caches, run diff book.xlsx. A cache has the provenance of the file that supplied it.

On workbook commands, --json writes one JSON object to stdout. Use the command and exit status to interpret it. Fields may change with the pinned build.

  • recalc reports book, macros, and counts for formula_cells, calculated, refused and not_current. With --out, it also reports saved with path and bytes. Exit 1 indicates a refusal or a result that is still non-current.
  • diff reports book, macros, formula_cells, outcome counts, pass, fail, pass_rate and cells. Each row has cell and status (matched, mismatched, refused, missing or failed), and includes cached, calculated or detail where available. Only matched cells pass. The rate is matched divided by all formula cells, or 1 for an empty comparison.
  • get reports book, macros and cells. A cell row identifies cell and provenance, with formula, value, note and cached when available. Check provenance even on exit 0. set adds the edited cell rows to the recalc summary.
  • run reports book, macro, macros and a typed result. It adds saved when invoked with --out. The macros object describes the requested level and whether the file contains a project; when a project is present, ran is accompanied by policy or reason.
  • Values carry a type. Number, text, logical and error values include value. Nonfinite numbers use strings. Array values report rows and columns. Empty and reference values carry the type alone.
  • A command failure returns {"error":"message","exit":2} with exit 2. A worker panic exits 70. serve, help and version have their own output.

Rust entry points

These experimental crates are unpublished. Build the doctests and local rustdoc from the same checkout with cargo test --doc -p calc-host -p calc-fml -p calc-func and cargo doc --no-deps -p calc-host -p calc-fml -p calc-func. Open the crate indexes under target/doc.

  • Use calc_host::HostSession for a native workbook session. The workbook doctest opens a file, enters a formula, recalculates and saves. Inspect projected values for file caches, calculated results, stale values and typed refusals. The lower-level document and engine contracts explain persistence and recalculation.
  • Use portable calc_fml::parse_formula for editor diagnostics and UTF-16 spans. The parser doctest parses =SUM(A1:A3) and checks that it preserves the source.
  • Use portable calc_func::invoke for a catalogue call. The function doctest invokes ABS on a CalcValue with caller-supplied services. Inspect the returned value or typed refusal.
