Check a workbook without Excel

The Linux x86-64 runner recalculates Excel workbooks, reads and edits cells, and reports the result from a script.

dnacalc diff book.xlsx compares every formula cell with the workbook's saved value. --json writes a machine-readable result.

{{runner}}

For diff, exit status 0 means every formula cell matched. Status 1 means there were differing or refused cells. Status 2 means a usage error or a typed refusal.

Engine crates

The Rust workspace includes the function library, formula language, workbook engine and document layer. The crates are unpublished.
