The views

One workbook, five views

A spreadsheet grid shows every cell and hides the model. DNA Calc keeps the grid and adds four other ways to read the same workbook. The Classic grid is live as a preview. The other four are designed and being built, and this page says which is which.

What each view is for

ViewWho it is forToday
ClassicAnyone who edits at speed. Excel's grid, formula bar and keyboard. See the Classic Grid guide.The browser app has the established grid. The preview is the new grid: draw, select, edit and undo.
InspectorA reviewer. Trace a result to its precedents, group errors by the cell that caused them, watch what a recalculation changed.Designed. Not yet built.
NotebookAn analyst or teacher. Formulas in reading order, each with its value, table or chart beneath it, with Jupyter's keys. Every formula in the notebook is a real workbook cell.Designed. Not yet built.
Model mapAn engineer. Sheets, tables and named cells as boxes; references as counted wires; circular references shown as loops.Designed. Not yet built.
AppThe person who uses the model. Validated inputs and results as a form, declared as data in the file.Designed. Not yet built.
Formula ExplorerAnyone with one formula to understand. A tool beside the views; it needs no workbook.Live in the browser.

The four views in build follow milestones M4 to M7 of the skin architecture. This page changes when a view is published.

The rules every view follows

These are the design rules the views are built to.

  • The file stays Excel. Every edit made in any view is an ordinary Excel edit: a cell entry, a name, a format. No view adds a calculation feature that Excel lacks.
  • One selection and one undo. The views share the workbook's selection and its history. Ctrl+Z undoes the latest step whichever view made it.
  • Layout is kept apart from the model. What a view adds (a notebook's order, a map's layout, an App's pages) is stored in one separate XML part of the workbook, never in cells, formulas or hidden names.
  • A file carries no code for the views. Layouts, pages and themes are data. Opening a workbook runs nothing from them.
  • A change is shown before it is made. An edit from outside the grid names the cells it will write, or says that it changes presentation only.
