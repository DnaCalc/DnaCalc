Engine

Excel's answers, reproduced and measured

The engine is a Rust re-implementation of Excel's calculation. Its aim is Excel's answer to the last bit, and it is measured against answers recorded from Excel.

{{metrics}}

How the counting works

  • Workbook corpus. Each workbook was calculated and saved by Excel. The engine recalculates it and each formula cell is compared with Excel's saved value.
  • Function bank. Each row is one function call with its arguments and Excel's answer, compared as bits. {{bank_clean}}
  • A refusal is a failure. What the engine does not model returns a typed refusal that names the missing piece. It counts against the pass rate.
  • A saved value is never a pass. Only a value the engine calculated counts as calculated.

The hard cases have their own write-ups: PMT, the gamma family, NORM.S.INV, LINEST and number to text.

Use it from a script

The Linux x86-64 runner recalculates a workbook, compares it with the values Excel saved, and reads or edits cells. --json writes one JSON object.

{{runner}}

For diff, exit status 0 means every formula cell matched. The runner and its JSON are experimental; the engine guide pins a build and documents the output.

Use it from Rust

The crates are in the repository and are not yet published to crates.io. calc-host is a workbook session, calc-fml parses formulas and calc-func calls one function. The engine guide links a doctest for each.
