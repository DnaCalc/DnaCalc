Try an Excel formula

Change the formula or its inputs and inspect the answer in the live Formula Explorer.

{{live}}

A link can carry a formula. The formula stays in the part of the address after #, which a browser does not send to a server. Open {{explore:=PMT(6.5%/12,360,-250000)}}, {{explore:=LET(x,SEQUENCE(5),SUM(x*x))}} or {{explore:=NORM.S.INV(0.975)}} in Formula Explorer.

Compared with Excel

{{metrics}}

Every formula cell is in the denominator. A mismatch, a refusal and a missing answer each count as a failure. A value read from the file is never counted as calculated.
