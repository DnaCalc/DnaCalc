# Episode 1: DNA Calc on Windows — opening a real workbook with VBA and add-ins

- **Status:** Draft (`dc-6q2k.4`)
- **Target length:** 6–7 minutes
- **Audience:** Excel users on Windows who want a second spreadsheet that opens their workbooks, recalculates them the way Excel does, and runs their VBA and XLL add-ins.
- **The one thing shown:** Opening real Excel workbooks (`.xlsx` and `.xlsm`) in DNA Calc for Windows, enabling macros explicitly, loading an add-in, and switching between DNA Calc's six skins without losing workbook state.
- **Paired blog post:** [`docs/site/blog/2026-11-21-what-is-dna-calc.md`](../blog/2026-11-21-what-is-dna-calc.md)

## Exact files and setup

Prepare these repository fixtures on the Windows recording machine before starting the screen recorder:

1. **Application binary:** `dna-calc-desktop.exe` (Windows x64 desktop build; note on screen that the `0.2.0` signed installer is a preview candidate).
2. **Workbook 1 (modern formulas, tables, dynamic arrays):**
   - `crates/calc-doc/tests/fixtures/cdoc_m1_2/d1.xlsx` (generated by `make-fixtures.ps1`; two sheets: `Data` with numbers, styles, and the `Sales` table `D1:F7`; `Calc` with `_xlfn.SEQUENCE(3,2)`, `_xlfn._xlws.SORT`, blocked spill `#SPILL!`, empty `FILTER`, `XLOOKUP`, structured reference `SUM(Sales[Units])`, and named ranges).
   - Also keep `d1.saved.xlsx` in the same folder or open `d1.xlsx` directly to show DNA Calc calculating formulas that carry no cached values.
3. **Workbook 2 (VBA `.xlsm`):**
   - `crates/calc-xll-reference/fixture/vba/DnaSimple.xlsm` (contains `DnaSimple.bas`: 109 tested worksheet functions including `SimpleNeg`, `SimpleSeq`, `SimpleMixed`, `SimpleWsMax`).
4. **Add-in 1 (VBA `.xlam`) and Add-in 2 (Excel-DNA `.xll`):**
   - `crates/calc-xll-reference/fixture/vba/DnaExamples.xlam` (`DnaAdd`, `DnaGreet`, `DnaDictType`, `DnaWhere`).
   - Built from `crates/calc-xll-reference/fixture/X2Hello.csproj` (`Hello.cs`): `X2Hello-AddIn64.xll` exporting `=SayHello(name)` (built with `dotnet build -c Release crates/calc-xll-reference/fixture/X2Hello.csproj`).

Keep **Macro security** in its default `Off` / prompt posture at the start of recording so the `Macros are disabled` bar appears naturally when `DnaSimple.xlsm` opens.

## Script

### Scene 1 — What DNA Calc is (0:00 – 0:45)

**Screen**
- Desktop showing `dna-calc-desktop.exe` open on an empty workbook, clean light or dark theme (`Settings & diagnostics` -> `Theme`).
- Brief view of the top mast: `DNA Calc`, document name, `New`, `Open`, `Save`, `Add-ins (0 loaded)`, `Undo`, `Redo`, `Calculate`, `Automatic` / `Manual`, and the skin switcher (`Grid`, `Notebook`, `Atlas`, `Tree`, `Canvas`, `Ledger`).

**Narration**
> "This is DNA Calc — an open-source, MIT-licensed spreadsheet written in Rust that opens Excel workbooks and calculates them the way Excel does, down to the last bit of every double.
>
> Today I'm running the Windows desktop preview. There is also a WebAssembly browser build and a Linux command-line runner, and they all share the same calculation engine. On Windows, the desktop app also loads native XLL add-ins and runs workbook VBA."

---

### Scene 2 — Opening an `.xlsx` with dynamic arrays and checking provenance (0:45 – 2:15)

**Screen**
1. Click **Open** in the top mast and open `crates/calc-doc/tests/fixtures/cdoc_m1_2/d1.xlsx`.
2. Show the `Data` sheet first: formatted numbers `A1:A5`, text `B1:B5`, and the `Sales` table in `D1:F7` with `SUBTOTAL(109,Sales[Units])` in `E7`.
3. Click the `Calc` sheet tab at the bottom.
4. Click `A1` (`=SEQUENCE(3,2)`): show the 3×2 dynamic-array spill in `A1:B3` and look at the **status line** at the bottom of the window (`Calc!A1: calculated by DNA Calc's engine`).
5. Click `H1` (`=SEQUENCE(2)`), blocked by `"blocker"` in `H2`: point out the `#SPILL!` result.
6. Click `S1` (`=XLOOKUP(3,Data!A1:A5,Data!B1:B5)` -> `item3`) and `R1` (`=SUM(Sales[Units])` -> `150`).

**Narration**
> "Let's open a real `.xlsx` first: `d1.xlsx` from our document test fixtures. This file was generated without any saved formula caches—every formula result you see here is being calculated live by DNA Calc's engine.
>
> On the `Calc` sheet we have dynamic arrays spilling with `SEQUENCE` and `SORT`, a blocked spill returning `#SPILL!` because there's text sitting in `H2`, structured table references like `SUM(Sales[Units])`, and `XLOOKUP` across sheets.
>
> Notice the status line at the bottom: DNA Calc always tells you whether a value came from a saved file cache or was actually calculated by the engine. We never pretend a stale cache is a calculated answer."

### Scene 3 — Six skins over the same live workbook (2:15 – 3:30)

**Screen**
1. Still on `d1.xlsx` (`Calc` sheet), select cell `P1` (`=SUM(ANCHORARRAY(A1))`) and click into the **formula bar**, typing `+1` without committing (or leave a clean selection, or undo/redo after a quick edit) — better: first change `Data!E2` from `10` to `25`, observe `Calc!R1` update from `150` to `165`, then start editing a cell or click the skin buttons:
2. Click **Notebook** in the skin switcher (`Grid`, `Notebook`, `Atlas`, `Tree`, `Canvas`, `Ledger`).
3. Click **Atlas** (point out the overview of sheets, formulas, inputs, and any refusals).
4. Click **Tree** (outline and dependents view).
5. Click **Ledger** and **Canvas**, then click **Grid** (or press the keyboard slot) to return to the familiar grid.
6. Press **Undo** (`Ctrl+Z`) to show `Data!E2` returning to `10` and `Calc!R1` returning to `150`.

**Narration**
> "One thing that makes DNA Calc different from a traditional clone is that the spreadsheet grid is only one view—one *skin*—over the open workbook.
>
> Up here in the switcher we have six skins: `Grid`, `Notebook`, `Atlas`, `Tree`, `Canvas`, and `Ledger`. When I switch from `Grid` to `Notebook` or `Atlas` or `Tree`, it doesn't reload the file. It re-projects the exact same live engine session. Selection, edit state, and undo history stay intact across every skin—we just finished cleaning up the skin internals so all six read through one controller and one shared cell projection."

---

### Scene 4 — Opening an `.xlsm` with VBA and enabling macros explicitly (3:30 – 5:00)

**Screen**
1. Click **Open** and choose `crates/calc-xll-reference/fixture/vba/DnaSimple.xlsm`.
2. Point directly at the macro bar that appears below the toolbar: `"Macros are disabled..."` with the **Enable macros** button.
3. Click a formula cell calling `=SimpleNeg(2.5)` or enter `=SimpleNeg(2.5)` in `H1` before enabling macros to show that VBA does not execute silently on open.
4. Click **Enable macros**. Show `=SimpleNeg(2.5)` recalculate to `-2.5`.
5. Enter `=SimpleSeq(3)` in `H2` (spills `10; 20; 30`) and `=SimpleWsMax(3, 9, 4)` in `H3` (`9`) to show VBA arrays and `Application.WorksheetFunction` working inside the workbook.

**Narration**
> "Now let's open a macro-enabled workbook: `DnaSimple.xlsm`.
>
> Just like Excel, DNA Calc holds the VBA project on open and shows the `Enable macros` bar—nothing runs until you click it. Notice that CalcDoc keeps the raw VBA project storage intact if you save the file back, while CalcVBA handles parsing and executing the modules.
>
> Once I click `Enable macros`, `=SimpleNeg(2.5)` evaluates to `-2.5`. And it isn't just trivial arithmetic: `=SimpleSeq(3)` returns a VBA `Variant` array that spills on the sheet, and `=SimpleWsMax(3, 9, 4)` calls back into `Application.WorksheetFunction.Max`. On our simple UDF suite, all 109 of 109 cases match Excel."

---

### Scene 5 — Loading an XLL or XLAM add-in on Windows (5:00 – 6:15)

**Screen**
1. Click **Add-ins (0 loaded)** in the mast to open the Add-ins menu.
2. Click **Load add-in…** (or paste the path into **Add-in path** and click **Load path**) and load `X2Hello-AddIn64.xll` (built from `crates/calc-xll-reference/fixture/X2Hello.csproj`).
3. Point out the loaded list showing the add-in path and registered function `SayHello`.
4. Type `=SayHello("Windows")` in an empty cell (`A1`) — show formula completion offering `SayHello` as soon as you type `=Say` — and press Enter to get `"Hello, Windows"`.
5. Optionally also load `crates/calc-xll-reference/fixture/vba/DnaExamples.xlam` and call `=DnaAdd(40, 2)` -> `42`.

**Narration**
> "Finally, let's load a native Windows XLL add-in built with Excel-DNA.
>
> Under `Add-ins`, I'll click `Load add-in…` and pick `X2Hello-AddIn64.xll`. DNA Calc hosts the XLL, runs `xlfRegister`, and feeds the registered functions straight into formula completion. So when I type `=SayHello("Windows")`, I get autocomplete and `"Hello, Windows"`.
>
> The same panel also loads `.xlam` VBA add-ins like `DnaExamples.xlam`."
