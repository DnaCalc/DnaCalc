The idea

An actor view of an Excel model

The rule throughout: the engine does what Excel does and nothing more, and the same workbook runs in Excel. Ptolemy II, from UC Berkeley, models systems as actors: boxes with ports, joined by wires, run by a director. The director is a component inside the model that decides what "running" means. The workbook already holds all of this; a skin can show it. Defined names give the boxes their identity (dotted names such as Shop.Stock already read like Ptolemy's dotted full names), references are the wires, and the way the engine recalculates is the director. Nothing here needs a new language: every box above holds an ordinary Excel formula, and the presented view is the formula-name presenter from the linked-boxes idea.

Directors a workbook already has

Recalcsynchronous-reactive · one fixed point

An edit settles every dependent name in one consistent step. This is plain Excel, and the default.

Iterationfixed point · maximum iterations, maximum change

Circular references allowed: the director repeats until values stop moving, using Excel's own two settings as its parameters.

Ticksdiscrete time · one recalculation per tick

Self-referencing state cells carry values from one tick to the next. This preview runs on it, as does the Circular Reference game.

Sweepparameter sweep · what-if data tables

A data table reruns the model once per input value; shown as a composite that fans one model out across a range.

Eventsdiscrete events · RTD, NOW, async

Live data and volatile functions wake the model. RTD topics become event sources with timestamps.

A realistic path, in milestones

  1. Read-only actor view.Boxes for defined names, wires from the host's existing precedents (with name edges added), values live. Layout kept in a skin part of the workbook, as the linked-boxes note proposes.
  2. Watch it calculate.The skin compares values before and after each calculation event and animates the names that changed, in dependency order. It uses only what Excel also exposes, so the same view can run as an add-in in Excel.
  3. Presenter.Dotted names shortened inside their group, a self-reference shown as the previous value (Stock⁻), IFS mode cells drawn as small state machines.
  4. Directors.Ticks and Sweep on top of iterative calculation and data tables, with a plotter fed from name histories.
  5. Edit by wiring.Dragging a wire rewrites the name's formula through the interpreter; the workbook stays an ordinary .xlsx that Excel opens and calculates the same.
Concepts inspired by Ptolemy II (ptolemy.berkeley.edu): actor-oriented modeling, directors, delays and modal models. No Ptolemy code or artwork is used. The model on this page is evaluated in the page from the formulas shown; it is a preview of a DNA Calc skin, not the engine.
