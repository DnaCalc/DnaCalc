# Fun

- `circular-reference.html`: Circular Reference, snake on a spreadsheet (2026-11-12). The snake is a growing `=SUM`; food cells hold numbers (0.1 and 0.2 show binary64 rounding), gold cells `=PI()`; error cells end the game with that error, hitting yourself is a circular reference, leaving the sheet is `#REF!`. Single page, open it in a browser. A formulas-only workbook version that DNA Calc calculates with iterative calculation is being built (lane game1).
- `watershed.html`: Watershed, the ambitious follow-up to Names in Motion: a hydro dam modelled in Excel formulas and run by nested directors as in Ptolemy II. Events (an RTD clock with run, step, rate and reset-when controls, and a seeded RTD price feed at its own rate; a price event recalculates only its dependents), Ticks (weather and reservoir with z⁻¹ state), a modal operator (Drought, Normal, Flood with hysteresis guards and a release rule per state), an Iteration director settling interest on average debt (a circular block, iterations shown), and a Sweep (a data table of 25 rainfall futures as an outlook fan). Look inside each composite; Actors or Sheet view of the same names; event queue strip; history and outlook charts; spec of the RTD clock (bead dc-hul4) and what DNA Calc needs.
- `names-in-motion.html`: Names in Motion, a skin-spec preview for the linked-boxes idea (dc-lvlj), inspired by Ptolemy II's actor-oriented modeling: a stock-and-reorder Excel model drawn as actors (defined names) with ports and wires (references), a director (Ticks: one recalculation per tick, Excel's iteration settings as its parameters), z⁻¹ delays for self-referencing state cells, an IFS mode cell as a state machine, a plotter, live parameters, firing order animated per recalculation, Excel formulas versus presented formulas, and a spec mapping Ptolemy concepts to workbook and DNA Calc pieces with a milestone path. The model is evaluated in the page from the formulas shown.
- `function-bank.html`: The Function Bank v3. New in v3: landscapes, a sample of each function's individual Excel answers (misses first) placed by argument value, coloured exact, ulp distance or differs in kind, zoomed to where the misses are; a gallery of the 18 most telling landscapes; and links that open a function (#NORM-S-INV). Landscape rows come from a full-bank judge trace via `tools/function_bank_landscape.py`, refreshed with `--land`. From v2: All 501 functions of the full bank as a zoomable packed map by Excel family (handbook categories), coloured by share matched or worst miss, sized by answers or equal; a day scrubber and play button replay the bank's git history (one snapshot per day since 2026-10-30, functions not yet in the bank drawn as ghosts); a detail card per function with the handbook description and verdict, a history sparkline, measured notes and open beads; a family ledger and an ulp ladder. Data embedded from witness-status.tsv and its history, the handbook build (handbook-preview/site/build/api/functions) and .beads/issues.jsonl; refresh it with `py -3 docs/fun/tools/refresh_function_bank.py --handbook ../handbook-preview/site/build/api/functions` from the repository root. d3 7.8.5 from cdnjs.
- `trace-error.html`: Trace Error, a spreadsheet detective puzzle: eight generated business models (budget to board pack), each broken once (a text "1O5" where a number belongs, a deleted reference, an =NA() placeholder); click cells to trace precedents with Excel-style arrows (red where the input carries an error) and name the cell where the error starts. Scored against the fewest traces. Its generator was tested headless on 2,400 models.
- `error-check.html`: Error Check: find the error cells hidden in a sheet. An opened cell shows its =SUMPRODUCT(--ISERROR(range)) count of neighbouring errors; Excel's green error triangle marks a suspected error; opening one shows how errors propagate.
- `spill-range.html`: Spill Range, falling dynamic-array spills (each piece is a formula such as =SEQUENCE(2,2) or a VSTACK with blanks; rotation is TRANSPOSE). A full row across A:J is summed and cleared; a spill with nowhere to go is #SPILL!.
- `what-does-excel-say.html`: a ten-formula quiz on Excel's surprising answers (-2^2, DATE(1900,2,29), 0.5-0.4-0.1, SUM over cell booleans, MOD(-1,3), LEN(1/3), ROUND(-2.5,0), WEEKDAY(1), FACT(171)). The function answers were checked live with Excel 16.0 build 20527 through the answer service on 2026-11-12: MOD 2, LEN 17, ROUND -3, WEEKDAY 1, FACT(171) #NUM!, DATE 60, SUM of cell booleans 0 and of literal TRUE,TRUE 2; the three operator formulas are Excel's documented behaviour.
- `dna-calc-brochure.html`: a one-page brochure laid out as a sheet, with the 2026-11-12 measurements and a binary64 bit explorer.

Both pages load fonts from Google Fonts and need no other files.
