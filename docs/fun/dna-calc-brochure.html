A2 · What it is

Excel's behaviour, rebuilt in the open

Every function, every recalculation rule and every odd corner of the file format is measured against Excel itself, then written as plain code under the MIT licence.

Functions

The full catalogue, from SUM to GAMMALN to XIRR, matched bit for bit, quirks included.

Workbooks

Opens .xlsx, .xlsm and .xlsb, recalculates with Excel's dependency rules, and saves files Excel opens again.

Macros and add-ins

CalcVBA runs workbook VBA, with an interpreter and a JIT. XLL and COM add-ins load too.

DNA OneCalc

A function workbench: try any formula, with completion and signature help, and see Excel's answer next to ours.

A4 · Try it

What "the last bit" means

Excel stores a number as 64 bits: one sign bit, 11 exponent bits and 52 fraction bits. Every Excel answer we record keeps those 64 bits, and a mismatch is counted in ulps, the steps between neighbouring numbers.

A5 · How it is checked

Excel is the referee

  1. Ask ExcelThree Excel processes on a private desktop answer up to 250,000 function calls at a time, with real ranges, arrays and spills.

  2. Keep every bitAnswers go into a bank of recorded observations, stored as hex bits with the Excel build that gave them.

  3. Find the shapeFor a wrong function, work out how the original code most likely computed it, then fit the constants. Never special-case an input.

  4. Judge it allEvery change is judged against the whole bank and the oracle workbooks. It lands when the net gain is clear.
