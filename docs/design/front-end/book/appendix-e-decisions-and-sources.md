## E.3 Seventeen `SKIN_ARCHITECTURE.md` A-vs-B Technical Adjudications (`dc-xnsw4`)

Where Fable's (`proposal-fable.md`, `dc-qttnl`) and Opus's (`proposal-opus.md`, `dc-uxiu1`) skin architecture proposals differed, [SKIN_ARCHITECTURE.md §2](../SKIN_ARCHITECTURE.md) adjudicated one canonical design:

1. **Contract crate granularity:** One portable `crates/calc-skin` crate (zero `calc-doc-model` / engine deps).  
2. **Level-0 split:** Pure synchronous `calc-formula-kernel` + stateful `calc-formula-host` below `calc-host` (`D-81`).  
3. **Watch coherency:** Atomic `Frame { stamp, events, updates }` bundles + `runtime.consistent()`.  
4. **Transport:** Four `Carrier`s with WebView2 shared binary buffers + Worker transferable `ArrayBuffer`s (`Interest::Anchors`).  
5. **Optimistic selection:** Monotonic `client_seq` + `SelectionCause` + `InputQueue` type-ahead.  
6. **Stamps & Undo:** One `HostSession` `History` with two-domain `Stamp { model, view, calc }` and `Revert(EntryId)`.  
7. **Chart rendering:** Keep `calc-chart-render` (`2.7 MB` Carlito fonts) host-side returning SVG + `ChartData`.  
8. **Pagination:** Move `printing.rs` (`1,285` lines) into `calc-host`, eliminating upward `apps/` dependency.  
9. **View/page/skin schemas:** Unified `dna.page/1` flow component tree + `dna.skin/1` manifest (`Try-On` banner for travelling themes/keymaps).  
10. **Notebook modes (`D-06`):** Single chain (`Command`/`Edit`), `Esc` holds unrun text, reader reports are `dna.page/1` in `Forms maker`.  
11. **Notebook layout (`NC01`, `NC06`):** Scalar rows + array column lanes (`Placement`); `#SPILL!` never auto-edits cells.  
12. **Extension sandbox:** Signed Rust-to-Wasm Web Worker `.dnaext` (`dna-ext-sdk`) over `Bound` slots returning Strand `RenderTree`.  
13. **View part & anchors (`D-13`):** Single `urn:dnacalc:views:v1` CustomXML item with `model` SHA-256 + 4-tier reconciliation; v1 deleted outright.  
14. **Agent workflow (`D-14`):** Schema-generated tools, `TryOn` for looks, `Proposal`/`Decide` subset preview for model, `<trail>` in CustomXML.  
15. **Macro runs & VBA views (`D-04`):** `begin_run`/`end_run` grouping + `ModelRoot::pin()` checkpoint in v1 (`DocumentOnly` M8 experiment); late-bound `Application.Run "DnaCalc.*"`.  
16. **Website <-> App links:** Privacy-preserving `#fragment` `Link`s + `<div id="onecalc">` + `HelpId` build checks.  
17. **Migration (`D-10`):** Move kept ~37.1k lines once (+ 51.3k in `calc-host`), freeze old page, build fresh views, delete ~39,400 legacy lines at Milestone 3.
