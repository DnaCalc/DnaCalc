## 6.1 Exact Jupyter Computation Chain with Pluto/Excel Live Reactivity (`CL-06-01`, `D-06`)

See [Pro 21 NC01 — Formula, result, next formula](http://127.0.0.1:8720/p21/notebook-compute.html#NC01) and [Pro 21 NC03 — Change one input; follow every result](http://127.0.0.1:8720/p21/notebook-compute.html#NC03).

Owner Ruling #6 (`D-06`) settles the Notebook's identity cleanly: **Notebook (`dna-view-notebook`, `Ctrl+Alt+3` / `Alt+Shift+3`) works strictly like Jupyter—an explicit computation chain where each written Excel formula sits visibly above its evaluated output, the next formula builds on that output by name or reference, and Markdown prose and cell-bound controls sit between the links of the chain** `[FRAMING-0009, FRAMING-0054, FRAMING-0056, FRAMING-0145, FRAMING-0171, P21-0014]`.

1. **No separate Read Mode (`D-06`):** There is no Author-vs-Read mode toggle and no formula-hiding `"Reading density"` inside Notebook; `Read-only` is solely a file-open capability (`Capabilities.read_only`) when a file cannot be edited `[FRAMING-0171]`. When an author wants a polished executive write-up or dashboard that hides formulas (`NC07` use case), that presentation is a `dna.page/1` page built in **Forms maker** and viewed in **App** ([Part VIII](08-app.md)) `[FRAMING-0056, FRAMING-0171, D-06]`.
2. **Pluto/Excel live dependency recalculation (no `[n]` run-order traps):** Unlike stateful Python kernels that drift out of order, every Notebook formula cell is a real Excel cell in `calc-host`'s dependency graph: editing any upstream formula or bound control (`Analysis!B2:B5`) immediately recalculates every downstream DataFrame, chart, and inline prose value in topological order with a brief green fresh underline—zero `"Run"` button required to clear stale cells (`R-18`) `[FRAMING-0148, P19-CARBON-0189, P21-0022]`. Reordering Notebook cells or switching to **Pipeline** layout changes reading presentation only and never alters calculation (`R-26`) `[P19-GPT-0256]`.
3. **Jupyter Command Mode & Edit Mode (`SKIN_ARCHITECTURE.md §7.3`):**
   - **`Enter`** on a focused cell enters **Edit Mode** (`dna-formula-ui` with `Ctrl+Space` completion, `FILTER(array, include, [if_empty])` signature help, `F4` anchoring, `F9` sub-eval, and range pointing) `[P21-0022]`.
   - **`Esc` in Edit Mode transitions to Command Mode while holding any unrun formula edit as a session-local held draft** (`"Edited · not run"`, keeping the prior committed value visibly labelled beneath and withholding downstream claims if incomplete; `Revert cell` discards the held draft, while `Esc` inside Classic/Bridge/prose editors restores the committed text) `[P21-0023]`.
   - **`Shift+Enter`** commits & advances/appends, **`Ctrl+Enter`** commits in place, **`Alt+Enter`** commits & inserts below (or inserts newline inside multi-line `LET` when editing text), and **`Run All Drafts`** commits all held drafts as per-unit history steps.
   - **Command Mode keys (`jupyter` layer):** `J`/`K` or `Up`/`Down` navigate cells; `A`/`B` insert above/below; `M`/`Y` switch Markdown prose vs formula cell; `D D` deletes; `C`/`X`/`V` copy/cut/paste cells; `O` folds output; `L` toggles line numbers; `/` opens the block inserter; `Alt+Up`/`Down` reorder (`Alt+P` toggles `Vertical` <-> `Pipeline`) `[P19-NEON-0052]`.

See [Pro 21 NC02 — Write the formula; name its result](http://127.0.0.1:8720/p21/notebook-compute.html#NC02), [Pro 21 NC05 — A function is a workbook name](http://127.0.0.1:8720/p21/notebook-compute.html#NC05), and [Pro 21 NC06 — A spill conflict, made concrete](http://127.0.0.1:8720/p21/notebook-compute.html#NC06).

### 6.2.1 Non-Mutating First-Run Card (`CL-06-02`, `D-55`, `R-20`, `R-43`)

Carrying forward legacy Flow keyboard ergonomics without legacy host coupling `[FRAMING-0074]`, opening Notebook on a workbook with no saved `notebook` declaration in `urn:dnacalc:views:v1` never silently dumps 40 sheets onto the stage; instead it shows a lightweight, non-mutating **First-Run Card** (`<=400 ms` on small cast workbooks, leaving `Stamp.model` unchanged and Mast state `saved`) offering three direct choices `[P19-FABLE-0053, P19-FABLE-0455, P19-GPT-0015, P19-NEON-0028, P19-NEON-0210, P21-0036, D-55]`:

1. **`Start with selected cells`** (e.g., `Add selected result Summary!B7` or `Insert linked table Monthly!B8:M11`) `[P19-GPT-0015, P21-0036]`.
2. **`Draft from workbook structure`** (`By sheet` or `Conclusions first`, with a `Why these?` evidence link and explicit sheet/output subset picker on large workbooks like `Inherited`) `[P19-FABLE-0053, P19-NEON-0052]`.
3. **`Blank notebook`** (allocating an `Analysis` sheet on first authored formula commit) `[P19-FABLE-0053, P19-NEON-0028]`.

### 6.2.2 Owned vs. Referenced Cells and Column-Lane Backing Sheet (`CL-06-03`, `CL-06-04`, `D-56`, `R-22`)

Every computing cell in Notebook is a real Excel cell (`R-22`—zero floating non-Excel math) `[P19-NEON-0212]`:

- **Single-anchor dynamic arrays by default (`D-56`):** Newly authored Notebook computation steps (`NC01`–`NC05`: `FILTER` -> `GROUPBY` -> `PIVOTBY` -> `SORTBY` -> chart -> `LET`) are single-anchor dynamic-array or scalar cells (`FRAMING-0146`, `P21-0035`), while existing multi-cell relative runs linked from sheets like `Budget!Monthly!B8:M8` render as unified **Run Cards** whose edits pass through the Preview Seam as one atomic step (`D-56`). Missing `if_empty` on `FILTER` produces real Excel `#CALC!`, propagated cleanly via explicit `IF(ISERROR($A$10),$A$10,...)` guards so zero stale prior tables or charts remain visible `[P21-0025]`.
- **Scalar zone + vertical array column lanes (`Placement`, `NC06`):** On the visible backing sheet (`Sales!Analysis`), `Placement` allocates bound inputs in `B2:B6`, scalar formulas above row 10 (`J2`, `J5`), notes in column `Y`, and dynamic-array spills in **separate vertical column lanes** starting at row 10 separated by spacer columns (`A:G` `scopeOrders`, `J:K` `byRegion`, `M:N` `byMonth`, `Q:R` `rankedOrders`, `U:V` `chartData`) so downward spill growth across 25,000 rows never collides `[P21-0017]`. Opening Classic side-by-side (`Ctrl+Alt+0`, `NC06`) outlines each worksheet anchor mapped 1:1 to its Notebook cell `[P21-0033]`.
- **Output naming & jump-to-producer (`NC01`, `NC02`):** Each output chip binds to a workbook Defined Name (`scopeOrders =Analysis!$A$10#`); clicking the chip renames it with Excel syntax/conflict validation and atomic downstream reference updates (`ModelChange::RenameName`) while keeping the cell anchor fixed, and clicking any Defined Name in a later formula or prose jumps straight to its producing cell `[FRAMING-0147, P21-0018, P21-0019]`.
- **Reusable `=LAMBDA(...)` function cells (`CL-06-05`, `NC05`):** Defining `MarginPct =LAMBDA(revenue,cost,IF(revenue=0,0,(revenue-cost)/revenue))` creates a workbook-scoped Defined Name rendered as a distinct **Function Cell** displaying its callable signature (`MarginPct(revenue, cost)`) rather than a fake scalar from an uncalled sheet cell, callable from any sheet `[FRAMING-0149, P21-0030]`.

## 6.3 DataFrames, Prose Live Chips, Controls, `#SPILL!` Recovery, and Live Tree (`CL-06-06`–`CL-06-09`, `D-57`)

See [Pro 21 N01 — Complete-scope data frame](http://127.0.0.1:8720/p21/notebook.html#N01), [Pro 21 NC04 — A live tree, inside the chain](http://127.0.0.1:8720/p21/notebook-compute.html#NC04), and [Pro 21 S05 — Blocked spill recovery](http://127.0.0.1:8720/p21/storyboards.html#S05).

1. **Windowed `DataFrame` & `View only` vs. `Changes the Table…` (`CL-06-06`, `D-57`, `R-20`, `R-44`):** Tables and dynamic arrays render with column types, sticky headers/totals, and a compact virtualised row window (`20` rows default, expandable to `200`/page) explicitly badged `"Showing 1–20 of 4,147 rows"`, while `FILTER`, `GROUPBY`, `PIVOTBY` (retaining its real month-header spill row without inventing extra months), `SORTBY`, `Find`, and aggregates evaluate across **all 25,000 source rows** `[FRAMING-0139, P19-CARBON-0191, P19-FABLE-0456, P21-0016, P21-0020]`. Column sort/filter clicks default to explicitly badged **`View only`** (`Rows` query—leaving Excel Table row order and positional references untouched), with a segregated **`Changes the Table…`** menu action that previews affected row shifts and commits with full Undo (`D-57`) `[P21-0039, P21-0040, D-57]`.
2. **Markdown `RichProse`, live `{=Name}` chips, controls, & shared RTD (`CL-06-07`, `R-21`, `R-27`, `R-45`):** Prose cells (`Source Serif 4`, 68 ch) embed live cell quotations inserted via `=` or `Insert value` (`{=Inputs!B3}`, formatted with the source cell's number format and showing a source link on focus; typing arithmetic inside prose offers to allocate a backing cell instead) `[FRAMING-0150, P19-FABLE-0055, P19-FABLE-0457, P19-GPT-0016, P19-GPT-0257, P19-NEON-0029, P19-NEON-0211]`. Inline controls (dropdowns, date-range sliders `Analysis!B2:B5`) write directly to ordinary cells, and live RTD cells (`Report!E2` `LARK` feeding `Analysis!J5`) share one subscription stream with Inspector (`I02`), clean up observers on navigation, and mark valuations `stale`/unavailable during feed outages without touching historical order totals `[P21-0024, P21-0027, P21-0029, P21-0041]`.
3. **Honest `#SPILL!` obstruction & 1-step relocation (`CL-06-08`, `R-29`, `NC06`, `S05`):** Calculation never triggers hidden sheet edits: if a growing `FILTER` hits an obstructing cell (`A16` in `NC06`, or `Summary!A21` blocking `A20` in `S05`), `#SPILL!` appears honestly and the Notebook offers previewed, undoable 1-step repairs—relocating only the obstructing cell/name (`reviewNote` `A16 -> Y10`, disabled if `Y10` is occupied) or relocating the array lane via Excel cut-and-paste `[P19-GPT-0018, P19-GPT-0259, P21-0031, P21-0032]`.
4. **Read-only Formula Lens & inline Live Tree extension (`CL-06-09`, `NC04`, `R-5`–`R-7`, `C-9`):** Formula Lens (`Alt+Shift+L`) displays readable terms alongside exact syntax without rewriting formulas or collapsing `RAND()+RAND()` (`Push-back #3`), while any `LET` or nested formula cell expands an inline **Live Tree** (`dnakode.live-tree` extension, `NC04`) showing each binding's current value, explicitly labelled `Expression structure` rather than execution order `[FRAMING-0152, P19-GPT-0090, P19-GPT-0235, P19-GPT-0236, P19-GPT-0237, P19-GPT-0308, P21-0026, P21-0038]`.
