## 8.1 Separating Model Operation (`App`) from Page Authoring (`Forms maker`) (`CL-08-01`, `CL-08-02`, `D-06`, `D-65`)

**App** (`dna-view-app`, reached via `Alt+Q -> App`, the Mast switcher, or `Alt+Shift+5`) is the calm, zero-code operator surface for Jo—managers, teammates, and domain users who run a model, test scenarios, or read an executive summary without editing spreadsheet mechanics `[FRAMING-0011, P19-FABLE-0095, P19-NEON-0221]`.

As established in [SKIN_ARCHITECTURE.md §7.5–7.6](../SKIN_ARCHITECTURE.md) and Owner Ruling #6 (`D-06`), `dna-view-app` registers **two distinct surfaces** over `dna-kit`'s shared `PageRenderer` (`dna.page/1`):

1. **`App` (`"app"` view — pure runner & executive reader):** Mounts the workbook's authored `dna.page/1` document in Reading density (`>=36 px` controls, collapsed Bridge, zero selection/resize handles, zero cell coordinates unless inspected via `See the cells`), keeping the Mast (`View as ▼` to Classic), standing 26 px Strip, and `F6`/`Alt` chrome keyboard-reachable at all times `[P19-FABLE-0086, P19-FABLE-0088]`. Under `D-06`, executive reader write-ups that hide formulas (`NC07` report style, combining `RichProse` live `{=Name}` chips, KPI cards, charts, and `NotebookExcerpt` outputs) live here as `dna.page/1` pages rather than inside a second Notebook mode.
2. **`Forms maker` (`"forms"` tool view — declarative page builder):** Reached via `Edit page…` or `Alt+Q -> Forms maker`, mounting the live `PageRenderer` with selection/reorder handles, a **Candidate Rail** (`Structure` + `Rules`: unlocked cells, validated inputs, Form Controls, terminal outputs, tables, charts), a Classic Companion picker, and a property inspector writing `PresentationChange::PatchDoc` steps.

**Authored opening vs. certain-signal drafting (`D-65`, `R-36`, `R-55`, `R-68`):**
- A workbook **never** auto-opens in `App` (`preferred="app"`) unless an author-confirmed `dna.page/1` App document exists in `urn:dnacalc:views:v1` (missing parts open in Classic; broken `Bound { anchor, address }` slots show **`Source missing`** and never snap to a nearby cell) `[P19-GPT-0044, P19-GPT-0266, P19-GPT-0298, D-65]`.
- When a user explicitly switches to `App` on an unconfigured workbook, DNA Calc displays a clean **`No App is defined yet`** card offering **`[Draft from file · Edit page…]`**—synthesizing a badged draft **solely from certain Excel signals** (unlocked cells on protected sheets, Data Validation lists, Form Controls, Scenario Manager, charts, `R-55`) on clean models while honestly declining unstructured 2,300-constant workbooks like `Inherited` (`R-68`)—alongside **`[Open Forms maker]`**, **`[Ask agent to draft]`** (`U05`), and **`[Open Classic]`** `[P19-FABLE-0148, P19-FABLE-0467, P19-GPT-0044, P19-GPT-0298, D-65]`.

## 8.2 Live Recalculation Default vs. Batched `Apply Inputs`, Validation, and Error Honesty (`CL-08-03`, `CL-08-04`, `D-66`)

See [Pro 21 F05 — Loan live App](http://127.0.0.1:8720/p21/app.html#F05), [Pro 21 A01 — Loan batched inputs](http://127.0.0.1:8720/p21/app.html#A01), [Pro 21 A03 — Stop validation refusal](http://127.0.0.1:8720/p21/app.html#A03), and [Pro 21 S10 — Jo runs Loan](http://127.0.0.1:8720/p21/app.html#S10).

1. **Live recalculation by default (`D-66`, `F05`, `S10`):** `Tab` visits editable white input controls in authored order (`R-56`); focusing an input reveals its inline seam caption (`Model change · Loan!B3`); committing a valid edit (`10.5% -> 12%`) recalculates KPI tiles (`R9,147.39 -> R10,286.13`), full-precision balance charts, and schedules within `<100 ms` with one-gesture `Ctrl+Z` Undo `[FRAMING-0137, P19-FABLE-0087, P19-FABLE-0468, P21-0076, D-66]`.
2. **Author-chosen Batched `Apply inputs` (`D-66`, `A01`):** For slow or multi-parameter models, authors set `"input": "batched"` on the `dna.page/1` page (displaying the reason beside the form); pending field drafts never relabel applied outputs (`Previous valid inputs`), **`Apply inputs`** commits all valid changes atomically as one Undo step, `Esc` reverts the focused field, `Discard` clears all drafts, and toggling back to Live asks before discarding pending drafts `[FRAMING-0137, P21-0078, D-66]`.
3. **Inline Validation & `#Error` Honesty (`CL-08-04`, `R-32`, `R-56`, `R-58`, `A03`):** Out-of-range entries (`principal <= 0`, `rate` outside `0–100%`, `term = 0` or `>360`) are refused inline at the field using the workbook's exact Excel `Stop` validation message (offering `Esc` exact revert and keeping applied results labelled `Previous valid inputs`—zero modal popups) `[P19-FABLE-0088, P19-FABLE-0468, P19-NEON-0222, P21-0077]`. If a valid input triggers a downstream formula error (`#NUM!`), affected output tiles show `#NUM!`, the red left tick, the plain trace-root explanation, and **`Undo my last change`**—never a blank or stale number (`R-58`) `[P19-FABLE-0090, P19-FABLE-0470]`.

## 8.3 Protected Outputs with Goal Seek, Native Scenarios, Schedules, and 1-Page Print (`CL-08-05`–`CL-08-08`, `D-67`–`D-69`)

See [Pro 21 A02 — Stock (ticked) operator panel](http://127.0.0.1:8720/p21/app.html#A02) and [Pro 21 S11 — Loan 1-page print proof](http://127.0.0.1:8720/p21/app.html#S11).

- **Write-protected outputs & inline Goal Seek (`CL-08-05`, `D-67`, `R-24`, `C-22`):** Formula KPI tiles reject literal typing (plus optional Excel Worksheet Protection on export) and offer **`See the cells`** (`Classic`) alongside an inline **Goal Seek** action (`Solve Loan!B2 Principal for R10,000/mo…`) that solves only a user-chosen unlocked input cell with full Undo and never overwrites formulas `[P19-CARBON-0040, P19-CARBON-0195, P19-CARBON-0228, P19-NEON-0115, D-67]`.
- **Native Excel Scenario Manager + transient `Pin Baseline` (`CL-08-06`, `D-68`, `R-33`, `R-35`, `R-57`, `R-59`):** Reusable saved scenarios read and write **Excel's native Scenario Manager** (or explicit workbook scenario columns—never a parallel CustomXML store), previewing changing cells on `Save as scenario…`, overlaying dotted baseline vs solid active curves on charts, showing numeric/% deltas on tiles, and supporting 1-step **`Reset`** to opening values (`R-59`), while **`Pin Current as Baseline`** remains a zero-friction, explicitly non-persisted session comparison `[P19-CARBON-0064, P19-FABLE-0089, P19-FABLE-0469, P19-FABLE-0471, P19-GPT-0265, P19-NEON-0223, D-68]`.
- **Windowed schedules, ticked operator controls, close summary, & 1-page Executive Summary print (`CL-08-07`, `CL-08-08`, `D-69`, `R-60`, `A02`, `S11`):** Schedules exceeding `50` rows render as a windowed frame (`360 payments · showing 1–12 · Expand all`) with an opt-in badged **`Group by Year (display rollup)`** toggle; `Stock (ticked)` (`A02`) shares `Run`/`Pause`/`Step`/`Rate`/`Stop condition`/`Reset` controls with Map and Inspector; `200%` zoom reflows 2 columns into 1; closing a modified workbook summarises edits in plain words (`You added 1 scenario and changed 2 inputs`, `R-60`); and **`Ctrl+P` (`S11`) defaults to a crisp 1-page Executive Summary** with live page-cost schedule checkboxes (`None [1 p]`, `Annual summary [+1 p]`, `Full 360-row schedule [+10 pp]`) `[P19-FABLE-0092, P19-FABLE-0093, P19-FABLE-0094, P19-FABLE-0201, P19-FABLE-0472, P21-0079, P21-0080, D-69]`.
