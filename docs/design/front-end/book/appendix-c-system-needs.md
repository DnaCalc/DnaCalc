# Appendix C. Consolidated System Needs (`C-01`–`C-38`)

Cross-reference: Parts II–XIV, [SKIN_ARCHITECTURE.md Appendix A](../SKIN_ARCHITECTURE.md) · Governing decisions: `D-04`, `D-09`, `D-13`–`D-15`, `D-81`, `D-83`, `D-88`, `D-89`
